# VOFA PID 滑条最小配置

## 固件

F103 正式固件：

```text
E:\\fan\\build\\f103\\fan.bin
```

当前版本已经烧录到软 4 F103，并完成 29124 字节读回校验。

固件同时完成两件事：

```text
USART1 输出 JustFloat：目标 RPM、实际 RPM、占空比
USART1 接收 VOFA+ ASCII 命令：KP、KI、KD
```

## VOFA+ 最小设置

1. 串口选择软 4 的 COM 口，设置 `115200`。
2. 接收数据引擎选择 `JustFloat`。
3. 在左侧命令栏新建一个命令，模式选 `Str/Ascii`。
4. 命令内容填：

```text
KP=%f\n
```

5. 右键当前数值滑条，选择“绑定命令”，绑定刚才的命令。
6. 将滑条范围设置为：`from=0`、`to=2`、`step=0.01`。

此时拖动滑条，VOFA+ 会发送例如：

```text
KP=0.8
```

后面带换行，固件会立即更新 Kp。

## 调参记录

固定物理电位器在同一目标转速，依次记录：

```text
Kp=0.2，Ki=3.0，Kd=0
Kp=0.8，Ki=3.0，Kd=0
```

如果需要调 Ki，把命令改为：

```text
KI=%f\n
```

滑条范围改为 `0..10`、步进 `0.1`。调 Kd 时使用：

```text
KD=%f\n
```

范围可设为 `0..0.2`、步进 `0.01`。

每组参数先清空 VOFA+ 波形，再使用相同目标和相同机械状态运行 15～30 秒后截图。

## 注意

- 物理电位器仍然负责目标 RPM，VOFA+ 滑条负责 PID 参数。
- 命令必须使用 `Str/Ascii`，不要使用 Hex 模式。
- 不要让滑条只发送裸数字；必须通过 `%f` 绑定到 `KP=`、`KI=` 或 `KD=` 命令。
- 改参数时固件会自动清除积分项。
