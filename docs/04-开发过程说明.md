# 04 · 编码器电机 PID 定速控制（模拟风扇） · 开发过程说明

对应《G308 电控组 2026 年夏季考核题》软件部分第四题。
硬件：STM32F103C8T6（正式目标）+ MG310 P30 编码器电机 + AT8236 驱动 + 扇叶 + 电位器。
仓库：[github.com/mydsp/fan](https://github.com/mydsp/fan)

## 1. 项目概述

以电位器作为旋钮给定目标转速，编码器测量实际转速，PID 闭环使风扇转速实时跟随设定值；
调节过程通过 VOFA+ 曲线与滑条在线改参直观呈现。整机使用 FreeRTOS 组织任务。

| 题面要求 | 实现 |
| --- | --- |
| （1）让电机转起来 | TIM3 双路 10kHz PWM → AT8236 → MG310 P30 |
| （2）ADC 读电位器，采样值越高转速/角度越大 | PA0 12 位 ADC 线性映射目标 RPM（被控量取转速，见 §7） |
| （3）PID 定速定位控制，VOFA+ 展示调参过程 | 10ms 位置式 PID + 滑条在线调参 + 三通道回传 |
| （4）用 FreeRTOS 完成 | `vTaskFan` + `vTaskBlink` |
| 提交：项目文件 / 开发过程简要说明 / 实操视频 | 本仓库 / 本文 / `docs/video/soft4-demo.mp4` |

## 2. 控制链

```
PA0 ADC（电位器）→ 目标 RPM → PID（10ms）→ TIM3 CH1/CH2 双路 10kHz PWM
                                  ↑                    ↓
                                  └── TIM4 编码器（PB6/PB7，4 倍频）← AT8236 ← 电机
```

| 项 | 值 |
| --- | --- |
| 控制周期 | 10ms（`vTaskDelayUntil` 对齐） |
| PWM | TIM3 CH1=PA6 / CH2=PA7，10kHz，CCR 即占空比 |
| 编码器 | TIM4，PB6/PB7，`TIM_ENCODERMODE_TI12`，IC 滤波 6 |
| 每转计数 | `ENC_CPR = ENC_PPR × 4 × 减速比 = 11 × 4 × 30 = 1320` |
| 转速换算 | `rpm = Δ计数 × 100 × 60 / ENC_CPR` |
| PID | 位置式，Kp=0.94 / Ki=1.6 / Kd=0，积分限幅 ±100，输出限幅 ±100 |
| 回传 | JustFloat 3 通道，50ms 一帧 |

## 3. 硬件与接线

| F103 引脚 | 连接 |
| --- | --- |
| PA6（TIM3_CH1） | AT8236 A01 |
| PA7（TIM3_CH2） | AT8236 A02 |
| PB6 / PB7 | 编码器 A 相 / B 相 |
| PA0（ADC1_IN0） | 电位器中间脚（两端接 3.3V / GND） |
| PA9 / PA10 | USART1 115200，USB 转串口 |
| 电机电源 | AT8236 Vin+/Vin-（独立 5~12V），与逻辑侧共地 |

驱动模块为 AT8236，采用 A01/A02 双输入 PWM 接口：两路输入直接决定方向与占空比，
无独立 STBY。相比"单路 PWMA + 方向脚 + STBY"的方案，方向与大小统一由一个
有符号占空比描述，PID 输出可直接使用，无需再做一次"符号 → 方向脚"的转换。
正转 CH1 输出 / CH2=0，反转相反，停止时两路均为 0。

## 4. FreeRTOS 任务设计

| 任务 | 优先级 | 栈 | 周期 | 职责 |
| --- | --- | --- | --- | --- |
| `vTaskFan` | idle+2 | 384 | 10ms | 解析调参命令 → 读 ADC 算目标 → 读编码器算实测 → PID → 写 PWM → 每 5 周期回传 |
| `vTaskBlink` | idle+1 | 128 | 500ms | 翻转 PA5 心跳灯 |

任务间通信采用"串口中断收字节进环形缓冲，10ms 任务统一解析"的方式：
调参命令低频且非实时，单独建任务或队列开销不划算；而放在中断里解析又过长。
心跳灯提供最廉价的存活指示——调度器正常与否先看灯，再看串口。

## 5. PID 实现

位置式：`out = Kp·err + integral + Kd·(err − err_last)`

- **积分限幅 ±100**：目标阶跃时误差大，不限幅会造成积分饱和、退饱和迟缓（刹车迟钝、超调）。
- **输出限幅 ±100**：对应 PWM 满量程。
- **目标死区（目标 <5 RPM 时清积分并强制 PWM=0）**：避免在极小误差上长时间做无用功导致电机微抖。
- **改参时清积分**：避免上一组参数的积分残留污染下一组观测。

## 6. VOFA+ 在线调参与调参结果

同一串口同时承担 JustFloat 回传（target rpm / measured rpm / duty，50ms）与 ASCII
调参命令（`KP=`、`KI=`、`KD=`、`PID=kp,ki,kd`、`RESET`）。配合上位机滑条，
一次烧录即可完成几十组参数对比。

调参按固定顺序进行：先 Kp（Ki=Kd=0，加到"跟得上但振荡"后退回振荡消失点的约 60%），
再 Ki（从 1.0 起，出现超调回摆减半），最后视噪声决定是否引入 Kd。
每组参数清空波形、固定目标与机械状态，运行 15~30 秒后截图。

| 截图 | Kp | Ki | Kd | 目标 rpm | 实测 rpm | 偏差 |
| --- | --- | --- | --- | --- | --- | --- |
| `docs/img/soft4-tuning-01.jpg` | 0.78 | 2.0 | 0 | 182.05 | 177.27 | −2.6% |
| `docs/img/soft4-tuning-02.jpg` | 1.24 | 0 | 0 | 70.62 | 63.64 | −9.9% |
| `docs/img/soft4-tuning-03.jpg` | 0.94 | 1.6 | 0 | 144.69 | 145.45 | +0.5% |

第二组说明纯比例控制的稳态误差只能靠积分项消除（Kp 加大也压不掉），
第三组即为最终参数。Kd 保持 0：编码器 10ms 差分测速在低速段抖动较大，
微分项会把该噪声放大为 PWM 抖动。

## 7. 被控量为何取"转速"

题面（2）原文为"使ADC采样值越高，电机转速**或**电机转动角度越大"——被控量本身二选一，
（3）的"定速定位"应与（2）连读：被控量选了哪个，就"定"在哪。

本题取**转速**：

1. 对象是风扇，物理目标是风量即转速；将扇叶定位到某角度对风扇既不可见也无用途。
2. （2）的"转速"分支已被闭环完整覆盖：ADC 越高 → 目标转速越高 → PID 将实测拉至目标。
3. "定位"在此语境下即"把转速定在设定值上"——消除稳态误差并抵抗负载扰动。
   演示视频中拧动电位器后实测转速数百毫秒内贴合新目标、手捏主轴加负载时占空比
   自动抬升且转速回稳，即为该过程的直观呈现。

若按"转角定位"理解，需将反馈从"每 10ms 计数增量"改为"起点起累计计数"
（`ENC_CPR = 1320` 计数/转，乘减速比换算输出轴角度），误差定义、积分行为与到位判定
需相应调整；编码器、驱动与回传模块均可复用。此为可选扩展路径。

## 9. 调试记录

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 烧录后无串口、无心跳、无 PWM | FreeRTOS 的 `vPortSVCHandler`/`xPortPendSVHandler` 未映射到 `SVC_Handler`/`PendSV_Handler`，调度器启动即 HardFault | 中断文件中显式建立映射；以 PA5 心跳灯作为调度器存活指示 |
| F103 串口实际波特率不对 | 时钟未显式配置，分频基准偏移 | 显式配置 HSE 8MHz×9=72MHz、APB1 36MHz（与软3 同类问题） |
| ADC 读数顶格或乱跳 | 电位器一端误接 5V，超出 VDDA=3.3V 量程 | 两端改接 3.3V/GND，映射上限按 3.3V 计算 |
| 转速恒为 0 / 一上电就满速 | 编码器 A/B 相序接反 / 反馈极性反导致 PID 正反馈 | 交换 A/B 相或修正误差符号；闭环建立前先打印原始计数确认反馈方向 |
| 电机啸叫 | PWM 频率偏低落入人耳敏感区 | 确认 PWM 为 10kHz，配合电机电感电流已较平滑 |

## 10. 已知限制

- 转速换算参数 ENC_PPR = 11、MAX_RPM = 300 定义于 fan.c 顶部，更换电机型号时同步更新。
- 测速为 10ms 差分，未加低通或滑动平均，低速段读数抖动较大；目前以 Kd=0 规避噪声放大，若启用 Kd 应先加测速滤波。
- 被控量取"转速"，"转角定位"的实现路径见 §7。
